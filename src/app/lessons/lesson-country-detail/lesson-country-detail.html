Country detail panel

The selection card is now a detail panel. Below the latest figures there is a line chart of the country's CO₂ since 1900, the median of its income group as a dashed line, and its rank in that group. A switch flips the chart between per person and total. Try Germany, China, India.

1. D3 does the maths, Angular draws

// charts/line-chart/line-chart.ts
x     = scaleLinear([1900, 2024] → [left, right])
y     = scaleLinear([0, max] → [bottom, top]).nice(4)
paths = computed(() => line().defined(v => v !== null).x(…).y(…)(values))

<path [attr.d]="p.d" />   // one per line, in the template
  • The classic D3 chart owns the DOM: d3.select(svg).selectAll('path').data(…).join('path'). In Angular that fights the framework: two systems updating the same elements, and cleanup by hand.
  • Here D3 only computes. Scales turn years and tonnes into pixels, line() turns points into a path string, ticks() picks round axis values. Everything else is ordinary template: @for over ticks, [attr.d] on a path. Same idea as lesson 03's flat map.
  • Every piece is a computed. Switch per person / total, or pick another country, and only the paths and ticks that depend on the change recompute. No ngOnChanges, no redraw function.
  • LineChart is generic: lines in ({ id, label, values, reference? }), a first year, a unit. It knows nothing about CO₂ or countries, so lesson 14's comparison can reuse it.

2. Honest axes, honest gaps

  • The y axis starts at 0. Starting at the minimum makes a 10% dip look like a collapse. Emissions are a quantity, so the bar of zero matters.
  • Missing years are gaps. line().defined(v => v !== null) lifts the pen over nulls. Many countries have no data before independence; the line starts when the data does, instead of diving to 0.
  • Tick labels in SI: y.tickFormat(4, '~s') prints 12 000 Mt as "12k", so the left margin fits China's totals and Chad's per-person figures alike.
  • A text alternative: the SVG has role="img" and an aria-label built from the data ("CO₂ per person in Germany, 1900 to 2024: from 5.86 t to 6.77 t"). A screen reader gets the trend without the picture.

3. Reading values: one readout, not a tooltip

  • Moving over the chart snaps to the nearest year: the pointer's x goes back through the scale (x.invert) and is rounded. The SVG scales with its box, so the pointer is first converted to viewBox units.
  • A rule and dots mark that year; the readout above the chart shows each line's value. Off the chart it shows the latest year with data. The readout doubles as the key (solid = the country, dashed = the peers), so there's no separate legend.
  • No floating tooltip: the panel already sits at the edge of the screen, and a readout in a fixed place is easier to compare while sweeping across years.

4. Peers: compared with whom?

// data/co2.ts
medianSeries(series, ids)        // year by year, the median of the group (null where fewer than 3 have data)
rankIn(series, ids, id, year)    // { rank: 1 = highest, of: how many had a value }
  • "High" or "low" only means something next to something. The peers are the country's income group (Natural Earth's World Bank classification, from lesson 02): it compares Germany with other rich countries, India with other lower-middle-income ones.
  • The median, not the mean: Qatar's 40 t per person would drag a high-income mean up by a tonne on its own. The median is "a typical country in the group".
  • The rank uses the chart's metric and the country's latest year. China is 1st of 57 upper-middle-income countries in total, but 8th per person: that's the point of the switch.
  • Caveat, said on the methodology page in lesson 19: the classification is a snapshot (several countries changed group since), and it's applied to the whole history. In 1950 South Korea wasn't high income.

5. The panel reveal (moved here from lesson 10)

shown   = signal<Country | null>(null)                 // the country on screen
current = computed(() => shown() ?? country())          // what the template reads

new selection → fade .nsc-country-detail out (0.25 s)
             → onComplete: shown.set(country())         // swapped while the panel is blank
             → afterNextRender: fade in (0.4 s)
  • Out, swap, in. The panel's content trails the selection: the old country stays on screen until it has faded out, is replaced while the panel is blank, and the new one fades in. The text never changes while visible. The frame (border, hatched shadow) is the host element and stays put; only the wrapper inside it, .nsc-country-detail, fades.
  • That's why the template reads current(), not the input: the input changes at once, current() only after the fade-out. Every computed (figures, chart, rank) follows current(), so they switch in the same frame.
  • Fast clicks: a selection made during a fade-out doesn't start a second one; when the fade-out ends it shows the latest selection. overwrite: true stops a fade-in still running when the next fade-out starts.
  • Earlier versions faded each row in one after another (stagger), then the whole block in without fading the old one out. Both read as jagged: the new text appeared at once, then faded.
  • Why afterNextRender: setting shown only schedules the DOM update. Fading in straight away would show the old country for a frame.
  • GSAP loaded on demand: await import('gsap'). The globe's chunk loads it anyway, but on the flat map (or without WebGL) it shouldn't join the first download. The build shows it as its own lazy chunk (~25 kB gzipped).
  • Reduced motion (MotionPreference, lesson 00): no fade, the content just appears.
  • The aria-live region is a wrapper that stays in the DOM. A live region that is created together with its content isn't announced by most screen readers.

Review checklist

  • Select Germany: per-person line above the dashed high-income median for most of the century, falling since the 1980s
  • Switch to Total, then select China: the rank changes between the two modes
  • Sweep the pointer across the chart: the rule snaps to years, the readout follows, and returns to the latest year when you leave
  • Select a country without early data (e.g. Namibia, from 1991): the line starts late, with no dive to 0
  • Select Western Sahara: "No CO₂ data", no chart
