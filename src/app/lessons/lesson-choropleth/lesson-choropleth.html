Choropleth and legend

The globe and the map are now coloured by data: CO₂ per person in the latest year by default. A legend in the bottom-left corner says what the colours mean, and its title is a switch: per person, per year, share of all CO₂ since 1750, consumption-based, GDP per person. Try per person, per year, historical share.

1. Colour by the job: one hue, light → dark

  • CO₂ per person is a magnitude, more or less of one thing. That calls for a sequential scale: one hue, from light (little) to dark (a lot). No rainbows: a rainbow has no natural order, so the eye can't tell whether green is more than yellow.
  • The palette is CARTO's BrwnYl (7 classes, sand to plum; chosen in lesson 12 after comparing 41 candidates on the globe, ColorBrewer's Oranges before that), made for exactly this: perceptually ordered, one direction from light to dark. Warm and earthy, fitting for carbon, and its darkest class is a muted plum rather than black, so ink borders and hatching stay readable on it. CARTOColors are CC BY 3.0: credited on the methodology page (lesson 19).
  • "No data" isn't a colour on the scale. It's white with light grey hatching, so it can never be read as "the lowest class". Western Sahara, Kosovo and the small dependencies from lesson 08 show up this way.
  • The selection hatching is now ink, not red: red lines on dark orange disappeared. The hatching leaves gaps, so the selected country's own colour stays readable.

2. Classes, and where to cut them

// charts/choropleth.ts
breaks     = quantiles at 1/7, 2/7 … 6/7 of all countries' values   (d3-array quantileSorted)
thresholds = breaks rounded to 2 significant digits                  0.43 · 1.2 · 2.4 · 3.7 · 5.3 · 8.6 t
colour(v)  = scaleThreshold(thresholds, 7 colours)(v)                (d3-scale)
  • Classed, not continuous: 7 colours the eye can tell apart and match back to the legend. A smooth gradient looks richer, but nobody can read "4.3 t" off it.
  • Quantile breaks: each class holds about the same number of countries (28–32 here). CO₂ per person runs from 0.03 t to 41 t. Equal-width classes (0–6, 6–12, …) would paint nearly every country the palest orange and spend six colours on a dozen Gulf states. A log scale is the other common fix; quantiles also handle metrics that aren't log-shaped, like GDP.
  • The price of quantiles: the classes are unequal in width (0.43 to 1.2 is narrow, 8.6 to 41 is wide), so the legend must show the breaks. Each metric gets its own breaks, recomputed when you switch.
  • Rounded breaks: 2 significant digits, so the legend reads 1.2, not 1.1839. Rounding can make two breaks equal; those are merged, so the thresholds stay strictly increasing.
  • One year, honestly: the metric's latest year (2024; 2023 for consumption; 2022 for GDP). A country without a value in that year is "no data"; its older figure isn't shown in its place. The legend prints the year.

Later: a second way to cut (lesson 15)

  • Quantiles ignore how far apart values are. For annual CO₂ the top class (the 10 largest, 570 Mt and up) held China at 12,290 Mt and Russia at about 1,800 Mt in one colour: a 7× gap, invisible. It showed when countries were raised by their totals and China towered over a Russia of the same colour.
  • Metrics that span orders of magnitude (annual CO₂: under 1 Mt to over 12,000; the share since 1750: 0.001% to 23%) now get log breaks from the 1-3-10 ladder: 10 · 30 · 100 · 300 · 1K · 3K · 10K Mt. Each class is about three times the one below, so a 10× gap is always at least two colours. China now has the darkest colour to itself; the USA and India share the next; Russia sits two below China.
  • The top break is the largest rung at or under the biggest value, so the darkest class is never empty; the rest step down from it. The honest cost: 103 of 213 countries emit under 10 Mt a year, so for this metric most of the map is pale. That is the shape of the data.
  • The per-person metrics and GDP keep quantiles: their values are spread evenly enough for equal-sized classes to work. One setting per metric (METRIC_BREAKS in explorer-state.ts) chooses.
  • The legend's labels went compact (10K, 3K), so five-digit breaks fit under the swatches.

3. On the globe: a 1 kB palette texture

  • Lesson 05's ID map already tells the shader which country every pixel belongs to. Colouring adds a second, tiny texture: 256 × 1 pixels, slot n = the colour of country n. Alpha 255 = has a value, alpha 0 = no data.
  • Switching metrics rewrites those 1 024 bytes (GlobeScene.setFills) and draws one frame. The 8 MB ID map isn't touched.
  • The texture is marked SRGBColorSpace: its bytes are CSS-style colours, and Three.js converts them to linear for the shader, so #d94801 on the globe matches #d94801 in the legend.
  • Hover darkens a country's colour by 18% instead of replacing it, so you still see its class while pointing at it.

4. On the flat map: inline fills

  • FlatMap gets a fills input (country id → colour) and binds [style.fill] on each path. The 240 path strings from lesson 03 aren't rebuilt; only the fills change, with a short CSS transition.
  • The bug: the first version bound [attr.fill] and every country stayed white. The stylesheet's fill: var(--surface) outranks an SVG attribute, but not an inline style.
  • No data uses an SVG <pattern>, the same hatching as on the globe. The selection pattern is now transparent between its lines.

5. The legend: generic, with a slot

  • charts/legend/legend.ts takes thresholds, colours, a unit and a year. It draws the swatches, the breaks between them, and a "no data" swatch. It knows nothing about CO₂.
  • The metric switcher is the explorer's <select>, projected into the legend's [legend-title] slot: same pattern as FloatingPanel (lesson 01) and the tooltips.
  • The metric lives in the URL (?metric=co2), like the country and the view (lesson 07). Switching replaces the history entry. The default leaves the URL clean.
  • Tooltips now show the hovered country's value: "United States of America · 4,900 Mt per year", or "no data".

6. Loading the right metric

private readonly mapSeries = computed(() => {
  const id = this.state.metric();
  return untracked(() => this.co2.metric(id)); // creates the resource on first use
});
  • Co2Data.metric(id) creates a resource the first time, which starts a request and registers effects: a side effect. Angular doesn't allow that inside a tracking computed. untracked() runs it outside tracking, while the computed still re-runs when metric() changes.
  • Per person is shared with the selection card (lesson 08), so the default view loads nothing extra. Other metrics are downloaded the first time they're chosen, then cached for the session.

Review checklist

  • Default view: Europe, Russia, the Gulf dark; the Sahel and Central Africa palest; Western Sahara hatched
  • Switch to "Annual CO₂ emissions": China, the USA, India darkest; small countries go pale; the legend's breaks change
  • Switch to GDP per capita: the year in the legend becomes 2022
  • Select a few countries: the figure in the panel falls in the class its colour shows (the tooltip showed the value at first; it now shows the name and the income meter)
  • Select France: ink hatching over its orange, which stays readable
  • Switch to the map: same colours, same legend; reload: same metric (it's in the URL)
