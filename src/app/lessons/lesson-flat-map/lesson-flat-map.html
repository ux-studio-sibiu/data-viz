Flat map first (SVG)

The explorer now draws the lesson 02 data: 240 countries as an SVG map, with a tooltip on hover. Before the globe, because a flat map isolates the D3 part from the Three.js part, and because it stays useful: in lesson 18 it becomes the fallback for devices without WebGL.

1. D3 does the math, Angular renders the DOM

Classic D3 owns the DOM: d3.select(svg).selectAll('path').data(features).join('path').attr('d', path). In Angular (or React) that fights the framework, since two systems would be updating the same elements. Here D3 only computes, and the template draws:

// flat-map.ts
private readonly path = computed(() => geoPath(this.projection()));
protected readonly countries = computed(() =>
  this.features().map(f => ({ id: f.id, d: this.path()(f) })));

<!-- flat-map.html -->
@for (c of countries(); track c.id) { <path [attr.d]="c.d" [attr.data-id]="c.id" /> }
  • Only d3-geo is installed, not the whole d3 bundle. Its job: geoPath(projection)(feature) turns lon/lat polygons into an SVG path string.
  • The 240 path strings are built once, in a computed(). They're rebuilt only if the features or the projection change, never on hover. ≈ useMemo.
  • track c.id ≈ React's key. Lesson 09 will recolour countries; the paths stay, only their fill changes.
  • SVG attributes need [attr.d], not [d]: d isn't a DOM property, only an attribute.
  • @if and @for work inside <svg>. Angular creates their <path>s in the SVG namespace because the compiler sees they're inside an <svg>.

2. The projection

  • Equal Earth (geoEqualEarth): every country keeps its true area relative to the others. On Mercator, Greenland looks as big as Africa; it's 14 times smaller. When colour and size carry data (lesson 09), the map shouldn't distort them.
  • fitExtent([[8, 8], [952, 492]], { type: 'Sphere' }) scales and centres the whole world inside the drawing.
  • The drawing is always 960 × 500 units. The viewBox scales it to any screen width, so nothing is recomputed on resize: no ResizeObserver, no listener.
  • d3-geo cuts shapes at the map edge on its own: Russia and Fiji cross the 180° meridian and are split cleanly. The globe in lesson 05 has to deal with this itself.

3. Loading: the Boundaries service

  • data/boundaries.ts loads both lesson 02 files with two httpResources. They run in parallel, and features is ready when both have arrived.
  • It converts TopoJSON to GeoJSON with topojson-client's feature(), attaching each country's name and label point from countries.json.
  • providedIn: 'root': one instance for the whole app, so the explorer, the globe (lesson 04) and the search list (lesson 07) share the same download.
  • The explorer shows "Loading the map…" and an error state with @if / @else if, reading isLoading() and error().
  • Before writing the map, a one-off check covered the polygon winding order (d3.geoArea of every country). d3-geo treats a ring drawn the wrong way round as "everything except this country", and the map fills with one colour. Here, no country covers more than half the sphere, so the order is right.

4. Hover: delegation, two-way state, a slot

  • One listener, not 240: (pointerover) sits on the <g> and reads data-id from whichever path the pointer entered. ≈ $('g').on('pointerover', 'path', fn). Pointer events also cover touch: a tap shows the tooltip.
  • hovered is a model(): the map writes it, and the explorer reads it with [(hovered)]. Later, a search list or the globe can set it too, and the map highlights whatever is chosen elsewhere.
  • The highlight is drawn twice: the hovered country is repeated at the end of the SVG. SVG has no z-index; later elements paint on top, so the outline isn't hidden under the neighbours' borders.
  • The tooltip is a slot: the map decides where (the projected label point, as a % of the drawing), the explorer decides what (name and subregion). Same idea as FloatingPanel's slots in lesson 01. The map knows nothing about subregions.
  • Hover France: French Guiana and Réunion light up too. That's the MultiPolygon, one shape with several parts. The label point keeps the tooltip over mainland France; a centroid of all the parts would land in the Atlantic.

5. What's missing, on purpose

  • Microstates are there (Vatican, Monaco, Nauru), but too small to point at on a 960-unit map. Lesson 07 adds a searchable country list for them.
  • Keyboard: 240 tab stops would be worse than none. The same list in lesson 07 is the keyboard way in.
  • Zoom and pan: the globe in lesson 04 covers that.

  • Hover France, Norway (Svalbard), the USA (Alaska, Hawaii): one country, several parts
  • Resize the browser: the map scales, and nothing is recomputed (no resize code)
